\# 💼 Job Salary Prediction System



\##  Project Overview



This project is a complete Machine Learning application designed to predict employee salaries based on several professional and educational factors.



The project uses a large-scale dataset containing 250,000 job records and applies different Machine Learning algorithms to compare their performance and select the best predictive model.



The final application also includes an interactive web interface developed using Streamlit.



\---



\#  Objectives



The main objectives of this project are:



\- Perform Exploratory Data Analysis (EDA)

\- Preprocess and clean the dataset

\- Train multiple Machine Learning models

\- Compare model performances

\- Optimize hyperparameters using GridSearchCV

\- Build a salary prediction web application using Streamlit



\---



\# 📂 Dataset Information



Dataset: Job Salary Prediction Dataset



Features:



\- job\_title

\- experience\_years

\- education\_level

\- skills\_count

\- industry

\- company\_size

\- location

\- remote\_work

\- certifications



Target Variable:



\- salary



Dataset Size:



\- 250,000 records

\# 🤖 Machine Learning Models



The following regression models were tested:



1\. Linear Regression

2\. Decision Tree Regressor

\---



\#  Evaluation Metrics



The models were evaluated using:



\- MAE (Mean Absolute Error)

\- RMSE (Root Mean Squared Error)

\- R² Score



Cross-validation and hyperparameter tuning were also performed.
